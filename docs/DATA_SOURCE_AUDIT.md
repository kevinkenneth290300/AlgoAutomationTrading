## 1. Executive Summary & Audit Methodology

This audit inspects every data element, metric, calculation, chart point, and status indicator displayed in the platform's user interface. Its purpose is to eliminate synthetic illusions, ensure rigorous provenance categorization, and enforce clear separation between:
1. **REAL**: Directly sourced from authenticated or public CoinDCX Futures endpoints / live WebSocket streams.
2. **PAPER**: Generated by the internal deterministic Paper Execution & Risk Engine using real market prices.
3. **BACKTEST**: Evaluated across historical normalized candle datasets without lookahead bias.
4. **MOCK**: Explicitly isolated sandbox simulation used ONLY when explicit mock mode is requested or credentials are absent.
5. **CALCULATED**: Pure mathematical transformations (e.g. EMA, VWAP, Sharpe, Sortino, Drawdown) executed on real data inputs.

## 3. Discovered Anomalies & Correction Directives

1. **Simulated Candlestick Generator in Production Code Path**:
   - `CoinDCXFuturesAdapter.getMarketData()` was falling back to `generateSimulatedCandles()`.
   - **Correction**: Connected directly to `https://public.coindcx.com/market_data/candlesticks?pair={symbol}&from={from}&to={to}&resolution={res}&pcode=f`.
2. **Hardcoded Prices & Balances**:
   - Fallback known prices (`BTC: 65420.5`) in `adapter.ts`.
   - Wallet balances hardcoded to `$10,000.00` in mock/adapter.
   - **Correction**: Replaced with live CoinDCX balance fetch when keys are present, or clean Paper Account ledger when in Paper mode. Real accounts without keys explicitly display "NOT CONFIGURED".
3. **Hardcoded Trade Indicator Math**:
   - `TradeView.tsx` had `const emaValue = c.close * 0.999`.
   - **Correction**: Implemented proper sliding-window Exponential Moving Average (`calculateEMA`) and Volume Weighted Average Price (`calculateVWAP`).
4. **Hardcoded System Reliability**:
   - `SystemView.tsx` had a static `<div className="...">99.4%</div>`.
   - **Correction**: Dynamically computed from system health monitor tracking real HTTP error counts and uptime.
5. **Pre-populated Strategy Performance**:
   - `StrategyRegistry` had hardcoded `validationScore: 88, sharpeRatio: 2.14`.
   - **Correction**: Initialized as unmeasured (`validationScore: undefined`, `sharpeRatio: undefined`); displayed in UI as "NOT TESTED" until real backtest is executed.
